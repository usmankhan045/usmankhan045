# ⭐ Featured Work

## 📝 MDTool — Open Source

**MDTool** is my open-source, browser-based document conversion
toolkit for working with Markdown, HTML, PDF and Word documents.

It is released under the **MIT License** and provides browser-based
document processing with a focus on usability and privacy.

### ✨ Features

- Markdown → PDF
- Markdown → HTML
- Markdown → Word
- HTML → Markdown
- Word → Markdown
- Markdown table generation
- Mermaid diagram support
- Syntax highlighting
- Browser-based document processing
- Privacy-focused workflows
- Developer productivity tools

### 🛠️ Built With

`Next.js` `React` `TypeScript` `Tailwind CSS`
